How we scored this

What a streaming platform actually screens on

The cloud fit column is not a marketing rating. It is scored against the deliverable and technical requirements in the streaming licences Aurora Punks has already signed, so it reflects what an integration team will ask for rather than what a trailer promises.

Technical

  • Native Linux build is the preferred execution target. Windows is accepted, but Linux is cheaper to run at scale.
  • Full controller support, since the end device is a TV, a set-top box or a handset with a pad. Partial support is a blocker.
  • DRM free packaging, delivered as a self contained flat archive.
  • Save data written to an identifiable file or path, so progression can be extracted and reinjected between sessions.

Editorial and commercial

  • Offline single-player. A multiplayer-only title cannot serve a solo subscriber.
  • Localisation breadth, EFIGS first, then territory languages.
  • Short session length, which suits living-room and set-top usage.
  • Low visual bitrate cost. Slow or static frames cost less to stream, which improves the revenue split under time-spent accounting.
Rights

Who signs what

Owned and Publishing rights

  • Owned. Aurora Punks group controls the IP and the storefront. We can licence these directly, on our signature alone.
  • Publishing rights. Aurora Punks holds the publishing mandate and a revenue interest. A streaming licence is available, with the developer countersigning.

Brokered and Not available

  • Brokered. The studio owns the IP. Aurora Punks has the relationship and full storefront access, and can introduce and structure the deal, but the studio signs.
  • Not available. Listed for completeness. The rights position is unresolved, so we are not offering it.
