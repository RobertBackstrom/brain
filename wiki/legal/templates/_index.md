# Reference Contract Templates — Full Catalogue

Exhaustive reference list of contract templates and noteworthy precedents on file. Companion to the [[reference_contract_templates]] skill (which curates "start here" masters + clause patterns).

**Scope:** templates the AP / CZP / Runatyr orbit owns or has collected. Counterparty templates are kept too — they're useful as comparison material when redlining or when a counterparty's house style is the right starting point.

**Maintenance:** when a new template is authored or collected, append the row. When a template is superseded, mark `status: superseded` and link to the replacement. Entries should be kept short and link out — this is an index, not a clause library.

## How the Lawyer agent maintains this

1. New template authored or collected → append a row. ID + status + notes only; clauses live in skills.
2. Template superseded → mark `status: superseded`, add a note linking to the replacement. Don't delete (the precedent matters).
3. Standing gap closed (3rd successful use) → promote to a real template via [[contract_workflow]] storage layers.
4. Cleanup candidates flagged in callouts above — work through during housekeeping passes.

For the curated "start here" subset + K2C clause patterns, see [[reference_contract_templates]]. For the legal-process flow, see [[contract_workflow]].
