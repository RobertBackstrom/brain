Before any significant UI/visual redesign, ask Robert for **reference images** and then ask 2-3 crisp **framing questions** in the same message (color logic, palette/theme direction, density tradeoffs, etc.).

**Why:** UI redesigns have many degrees of freedom; guessing on direction burns iterations. Robert has specific aesthetic opinions and usually has references in mind — surfacing them upfront saves a rewrite. He explicitly called this out on db-017 phase 3 (2026-04-14): asked for the reference, then confirmed "bg to white, hexes black with white iconography" — a direction I would not have picked without asking.

**How to apply:** Any time the task involves rethinking a visual language, page layout, color palette, hex/card style, or introducing a new view. Not needed for small tweaks (padding, one color, one icon swap). Pattern:
1. "Got any reference images or sites you like the feel of?" (or acknowledge the one he sent)
2. Two or three bulleted questions with (a)/(b)/(c) options, each with a one-line tradeoff
3. State a recommendation and why, so Robert can confirm or redirect with one reply
