Aurora Punks holds the publisher mandate on these titles, which is what lets us submit them to
festivals, showcases and awards without asking anyone first (Robert, 2026-08-24):

- **Chenso Club** - rights **reverted from Curve Games back to AP**. The Steam page still credits
  Pixadome / Curve Games, so the store is not a reliable source here. Developer is still Pixadome.
- **Block'Em!** - same reversion. Store lists Aurora Punks + IndieArk; AP is the mandate holder.
- **Distant Bloom** and **Go Fight Fantastic** - **AP is publisher**, not merely "lite publishing
  support" as the older project memories phrase it. Kinda Brave / Windup is the developer side.
- **Ooglians** - AP published, Cat Shawl Games / Simon Bäckström developing.
- **KreatureKind** - AP published, Valiant Game Studio (Anna Högberg Jenelius) developing.
- **Tears of Adria** - Ark Island Studio, self-published. Robert holds equity and sits on the team
  with full Steamworks access, so AP can act on it directly.

**Why:** a store page is not proof of who may submit a game. Chenso Club and Block'Em! both read as
someone else's on Steam while actually being ours, and Distant Bloom / GFF read as lighter
involvement than they are. Getting this backwards means either declining an event we are entitled
to enter, or ticking an authorisation box we cannot honour.

**How to apply:** before any outward submission of a portfolio title, check this file rather than the
Steam page. When a form asks separately for developer and publisher, name the developer accurately
and put Aurora Punks as publisher, noting the reversion if the store still shows the old one.
