---
name: Add logo/CTA to social images
description: Social media images should have logo or CTA text overlay, not just caption text
type: feedback
---

When posting images to social media, add the game logo or a CTA text overlay to the image itself. Don't rely only on the caption for branding/CTA.

**Why:** Plain key art without branding doesn't stand out in feeds. Logo builds recognition, CTA text on image catches scrollers who don't read captions.

**How to apply:** Before publishing any image post, overlay the game logo and/or a short CTA using the brand guidelines fonts/colors. Use the existing PSD source files or generate overlays with the brand toolkit.
