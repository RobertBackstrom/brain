Standard Drive org for every CZP project (Robert 2026-05-29):

- All project folders live in one **`projects` Shared Drive** (Robert created it 2026-05-29; consolidate project folders out of the other AP-workspace Shared Drives into it).
- **Nested model:** each project has category folders `_legals`, `_deliverables`, and `_financials` (the last only where relevant), and EACH category folder contains `_working` and `_archive` children. Current/authoritative docs sit at the category root; drafts in `_working`; superseded in `_archive`.
- **Three latest-doc rules:** (1) category root holds one current copy per doc; (2) no version suffixes live (`_v2`/`_final` only ever in `_archive`); (3) move-on-completion: draft in `_working` → signed/approved up to root → superseded down to `_archive`.
- **External sharing:** share the specific document with externals, NOT the category folder (Drive children inherit the parent's sharing, so sharing `_legals` would expose `_working`/`_archive`). AP-board + Behold get folder-level access (fine).

**Why:** one place for all projects, and a clear signed-vs-working separation so the mother folder only holds executed contracts.
