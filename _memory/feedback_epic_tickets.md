---
name: Epic tickets per project
description: Every project/client/effort needs one Epic ticket in the DB that groups tasks, subtasks, activity, and time tracking
type: feedback
---

Every project, client, or effort must have one EPIC ticket in the Death Board. Tasks and subtasks link up to their Epic. Activity logs and time tracking roll up to the Epic level.

**Why:** Work for the same subject often gets scattered across multiple standalone tickets. Epics provide a single view of all activity for a project/client.

**How to apply:**
- At session start, check whether the referenced project has an Epic. If not, remind Robert and suggest creating one.
- When creating an Epic, migrate existing tasks/subtasks and their activity into it.
- New tasks for a project should always link to the project's Epic.
- Time tracking and activity summaries should reference the Epic as the top-level grouping.
