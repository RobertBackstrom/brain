Rule: Whenever BizDev starts work on a new title, prospect, or pitch, run a web scan for articles, reviews, press coverage, community sentiment, and any public marketing material **before** drafting copy.

**Why:** There is usually public history (reviews, press releases, YouTube coverage, community threads) that adds color and credibility to outreach. Missing it = generic pitch. Finding a quote, stat, or angle from existing coverage makes the message land.

**How to apply:**
- At the start of any BizDev project (new game pitch, prospect outreach, event prep), run `WebSearch` on the title + key variants (subtitle, platform releases, alt names).
- Capture notable quotes, review scores, release timeline context, community sentiment signals.
- Drop findings into the project's drafts folder as `web-scan.md` so subsequent drafts cite them.
- Applies to: any BizDev work, not just when Robert asks.
