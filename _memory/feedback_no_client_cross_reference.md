**Rule:** Never name another client, project, or engagement in any client-facing material - docs, emails, slides, decks, anything that will be seen outside Aurora Punks. This includes:
- Client names (Raw Fury, Blue Scarab, Kinda Brave, Striden, BADASS, Elias, etc.)
- Project codenames (K2C, Sands of Duat, Equinox, ToA, etc.)
- People at other clients (Tim Browne, Niclas Lagerlof, Imi, Oskar Hansen, etc.)
- Internal AP code language ("the K2C / RF setup", "same cadence we use with X")

Default to fully scrubbed phrasing. Talk about *how we work* in abstract terms - "the way Aurora Punks runs publisher engagements", "our standard milestone cadence", "the model we use on co-dev projects" - never link it to a specific client or game.

**Why:** Caught on the BSC Equinox project plan 2026-05-16: the intro paragraph and the payment-terms note both said "K2C / Raw Fury setup" as a credibility flex. Robert flagged it - "You can never mention other clients or projects unless I say yes." Confidentiality + professional discretion + protecting other clients' commercial terms. Even an off-hand reference like "we do this with Raw Fury too" gives away contract structure that those clients haven't agreed to share.

**How to apply:**
- Before sending or appending ANY text to a client-facing artifact, sweep for: client names, codenames, project names, people at other clients
- When tempted to invoke a precedent ("we did this on X"), reword to talk about the practice abstractly: "our standard practice", "the cadence we run on co-dev", "the way we structure milestone approvals"
- Only break the rule if Robert has explicitly said yes for THIS specific reference in THIS specific doc. Standing permission doesn't exist; "we've shared this case study before" doesn't transfer.
- Sweep tools: grep the draft against a needles list of known client/project/people names before delivery. Quick scan script pattern: scan doc body + table cells for known strings.

**Scope:** Applies to docs, emails, decks, contracts, social posts, LinkedIn messages, public talks, anything visible outside AP. Internal logs / output_log / memory files are fine.

Source project: BSC Equinox project plan, 2026-05-16.
