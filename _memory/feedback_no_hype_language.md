Don't use hype language like "doing some wild stuff", "insane tech", "game-changing" in outreach drafts. Robert's voice is direct and factual - state what the tech does, let the listener decide if it's impressive.

**Why:** Robert flagged "Elias has been doing some wild stuff lately" as not how he writes. It reads as salesy/overhyped.

**How to apply:** In outreach DMs and emails, describe capabilities plainly ("they've moved into real-time raytraced acoustics") instead of editorializing ("they're doing crazy/wild/amazing things"). The tech speaks for itself.
