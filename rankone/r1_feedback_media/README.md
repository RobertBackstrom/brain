## The "trend" feature (the cool part) — how Pulse is structured
Pulse frames a game's audience on a **temporal timeline**, not a static snapshot. This is powered by RankOne's **daily snapshot of the entire games DB + every game relation since early 2024**, so every metric carries month-over-month movement (rank ↑/↓ arrows, `NEW` tags, and deltas like `+1.0x affinity`, `-2.1% volume`, `+15.3%`).

Timeline sections (`FROM → PAST → PRESENT → FUTURE`):
1. **Signal depth header** — matching enthusiasts / total followers / analysed connections (e.g. 1,146 enthusiasts, 143,978 connections).
2. **Executive summary** — AI-generated, ending in prioritised actions (partnership, cross-promotion, creator alignment, feature inspiration, messaging).
3. **Creator distribution + funnel** — mid-tier creators (101–1k) dominate; Want-to-Play / Playing / Played split with reach.
4. **Library analysis** — keyword/tag cloud that defines audience identity (for Pragmata: "surreal horror" + "custom volume / stereo sound" audio controls).
5. **Preference radars** — genre / theme / game-mode / perspective, each with affinity multipliers vs library.
6. **Platform gravity** — device share + platform ownership + affinity.
7. **FROM (inflow / overlay)** — which external communities feed this audience; "top by conversion %" for pre-launch and live communities.
8. **PAST (core roots)** — foundational communities by affinity + reach.
9. **PRESENT (current gravity)** — "current obsession" over-index (e.g. 7.7x in *007 First Light*).
10. **FUTURE — unreleased demand** (wishlist/WTP; biggest upcoming competitors + collab targets) and **backlog intent** (released games bookmarked to play next = buying intent).

**Why it matters commercially:** the timeline + deltas are the recurring-use hook (a static snapshot gets scraped once; a trend you re-check monthly). The FROM/FUTURE sections turn audience data into concrete actions — who to cross-promote with, who to co-market with, which competitors to watch.
