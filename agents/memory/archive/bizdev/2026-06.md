## HTMAG Alert Spam and Festival Pipeline Management

- **HTMAG sends hundreds of duplicate festival alerts per deadline.** When a festival deadline approaches (e.g., DevGAMM, BIG Summer Showcase), HTMAG's Discord bot floods the #events channel with repeated notifications every 15-30 minutes for 3+ days (evt-019 had 75+ identical alerts in 24h, evt-020 had 500+ in 5 days 2026-05-08 to 2026-05-13). **Why:** HTMAG's bot has no dedup logic; it reads the festival deadline as "approaching" and sends a new alert on every poll cycle. **How to apply:** When creating an event ticket from an HTMAG alert, (1) consolidate the hundreds of duplicate activity lines into ONE entry ("HTMAG alert spam: 500+ duplicate notifications over 5 days", summarize the event details once), (2) do NOT treat alert-spam volume as signal strength — a single HTMAG email contains all needed info, treat duplicates as noise, (3) when reviewing festival backlogs during 4am sweeps, sort by creation date and recency, not alert-count. The festival pipeline (evt-015 through evt-038) currently has 22 backlog entries with zero status clarity — treat alerts as intake source only, not as progress tracking. ## Post-Event Follow-Up (Mixer → Demo Conversion)

- **The event mixer is top-of-funnel; the demo-with-the-engineer is the conversion step.** Post-NGC, the right follow-up to "all mixer attendees" is a thank-you that hands off to a low-commitment 1-on-1 hands-on session with the technical person (Erik), not a re-pitch. Same shape reusable for any future Elias event: thanks → "if you didn't get the full picture, here's the easy fix: book a hands-on with Erik" → booking link. Keep it short, one tech line (raytraced acoustics / GPU spatial / post-Metasound), no logos, no pitch. [Elias, 2026-06-05, process]
- **Mixer attendee BCC list = Luma guest export, not the registration notification emails.** Luma "Ny anmälan" notifications to Robert give names + running count only, NOT email addresses. For a BCC send you need the host guest CSV at `luma.com/event/manage/<evt-id>/guests`. Don't try to reconstruct the list from 28 notification emails - flag the one-click Luma export to Robert instead. The Elias mixer (evt-jFarlDDlyxElgbm) hit 46 attending + 3 waitlist. [Elias, 2026-06-05, tooling]
