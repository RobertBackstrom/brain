## Story hooks (high-value for pitch)

- **HoMM + auto-battler + Mount & Blade DNA.** The combination is the hook. Memory frames this as "HoMM3 DNA" and the project memory notes Battle Brothers + Wartales + Mount & Blade as the closest comp set (per Klaus / Adult World Gamer).
- **20×20 grid auto-battles.** Specific, mechanical, more interesting than "auto-battler". Use the grid number — feels like a hex/strategy game more than an idle game.
- **Locked main + replaceable supporting cast.** The Steam copy itself surfaces this: "Your main character is locked in. Good luck. The rest are replaceable." Funny + specific.
- **Up to 80 henchmen.** Scale callout from the official site. Pulls the game toward Mount & Blade rather than HoMM.
- **Resurrect a dead goddess.** Steam short_description's payoff. Lean into the absurdist tone — "a dragon problem, a few questionable artifacts, and far too much confidence."
- **Self-published, Robert holds equity.** Not a partner-agnostic pitch detail, but useful framing for partner conversations: cap table is open.
